# YuzinA Studio

歌ってみた MIX 依頼受付サイト。静的 HTML / CSS / JavaScript で構成し、GitHub Pages で公開しています。

公開先: https://kingkazuma1015.github.io/yuzin_A_studio/

## 2026-10-28 デザイン更新

- ダーク／ペーパー／朱色のレイアウト、独自の音波 SVG、スクロール連動の演出。
- 元の文章・料金・連絡先・既存素材・9作品を維持。
- 作品一覧は左右に連続するカルーセル。タッチの標準スクロールとマウスのドラッグに対応。
- ホバー、キーボードフォーカス、画面外、非表示タブ、低減モーション設定などに合わせて自動移動を停止。
- 動画は選択時のみ読み込み、自動再生しません。外部リンクとして開く操作も保持。
- ネイティブの FAQ とダイアログ、コピー失敗時の手動コピー案内、JavaScript なしの連絡先を用意。
- メールはページ内で直接送信せず、メールアプリで内容を確認して送信する方式です。

## 検証

Python 3 と Node.js が必要です。追加パッケージは不要です。

```sh
python3 tests/check_site.py
```

原文128項目、9動画、リンク、メタデータ、既存素材のハッシュ、HTML/ARIA、JavaScript構文、
カルーセル・メニュー・動画・メールの状態遷移を検証します。
DOMテストダブルは実機の見た目、タッチ、スクリーンリーダーの検証を代替しません。
