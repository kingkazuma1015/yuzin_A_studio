# YuzinA Studio

歌ってみた MIX 依頼受付サイト。静的 HTML / CSS / JavaScript で構成し、Netlify で公開しています。

公開先: https://yuzin-a-studio.com/

## 更新元と次回の開始手順

更新元は [kingkazuma1015/yuzin_A_studio](https://github.com/kingkazuma1015/yuzin_A_studio) の `main` です。
ローカル・クラウドのどちらでも、このリポジトリの最新 `main` から変更を始め、同じリポジトリへ保存してください。
このローカルの `origin` は更新元、`backup` は移行前の private バックアップです。
旧ローカル `main` は `archive/private-backup-main-20261109` に保持しています。

```sh
git status --short --branch
git remote -v
git fetch origin
git log --oneline --left-right HEAD...origin/main
```

未保存変更がなく、ローカルだけが遅れている場合は `git pull --ff-only` で更新します。
双方に変更がある場合は差分を確認して統合し、履歴を上書きしないでください。
その後、次のコマンドで公開時の記録に対するローカルと本番の一致を確認します。

```sh
python3 scripts/check_published.py
```

公開記録は `.deployment/production.json` に保存しています。全14ファイルの SHA-256、
公開元コミット、Netlify デプロイIDを記録し、不一致があれば照合は失敗します。
通信なしで手元のみを調べる場合は `--offline`、未公開の編集がある状態で本番だけを調べる場合は `--live-only` を付けます。
公開元コミットは配布したファイルの版です。その後の手順書・公開記録のコミットとは区別します。
公開記録を変更して不一致を隠さず、別環境の更新と意図した未公開変更を確認してください。
維持する仕様と保存・公開手順は `AGENTS.md` にも記載しています。

## 2026-11-09 公開版の同期とモーション追加

同期開始時の独自ドメインの公開版は、当時 GitHub Pages にあった `b955158` と異なっていました。
2026-11-09 に公開先から HTML、4つの CSS、JavaScript、参照画像を取得し、
ローカルの `77d3d88` に表示用ファイルの基準を保存しました。
これは公開ファイルのスナップショットであり、クラウド側の未公開ソースや設定の同期ではありません。
取得元・ファイルハッシュ・原文は `tests/published-baseline.json` に記録しています。

既存の色、書体、レイアウト、画像、文章、料金、リンク、受付バッジを維持し、
`motion.css` と `motion.js` で次の演出を追加しています。

- ヒーロー見出しの行ごとの表示と、スタジオ写真の緩やかなズーム・視差。
- 見出し、料金表、FAQ、案内、連絡ボタンの時間差表示と罫線の描画。
- 装飾用の実績数字のカウントアップ。本文の実績表記と料金は常に固定です。
- 依頼フローの進行線とステップ番号のスクロール連動。
- ボタンの最大3pxのマウス追従、画面内でのみ動くサービス音波。

追加ライブラリは不要です。通常のスクロール操作を保持します。
動きを減らす設定では追加演出を無効化し、非表示タブ、ウインドウのフォーカス喪失、
ダイアログ表示中は停止します。スマートフォンでは視差を抑え、タッチ操作でボタンは移動しません。
数字の演出が中断された場合も、公開時の正しい最終値へ復帰します。

追加した読み込みタグと作品情報を除き、公開 HTML、既存 CSS、既存 JavaScript、
参照画像が取得時と同じことをハッシュで検証します。原文と9作品の並びも検証対象です。
既存操作に加え、演出の停止・復帰・低減設定・モバイル条件の回帰テストを実行します。

ローカル表示:

```sh
python3 -m http.server 8088 --bind 127.0.0.1
```

`http://127.0.0.1:8088/` を開いて確認できます。`index.html` をブラウザで直接開くことも可能です。
ローカルで確認後、上記「本番への反映」のとおり独自ドメインへ公開済みです。

カルーセル・メニュー・動画・メール・追加演出の状態遷移を検証します。
